Non-Human Identity (NHI) & SPIFFE Extraction

The proxy inspects validated client certificates at the transport layer to extract URI Subject Alternative Names (SANs). When a valid SPIFFE URI SAN is present, it becomes the primary authenticated workload identity.

Active Authorization Policy Engine

Policies are loaded from YAML/JSON and strictly enforced with default-deny rules. Paths are normalized (canonicalizing percent-encoding, duplicate slashes, and dot-segments) to prevent authorization bypasses. 

policies:
  - identity: "spiffe://customer-a/prod/payment-agent"
    allow:
      - method: POST
        path: "/payments"
      - method: GET
        path: "/payments/*"

  - identity: "spiffe://customer-a/prod/reporting-agent"
    allow:
      - method: GET
        path: "/reports/*"

  - identity: "*"
    allow:
      - method: GET
        path: "/health"

Zero-Downtime Dynamic Trust Store Rotation

Root CA trust material can be hot-swapped at runtime without process restarts via atomic parking_lot::RwLock pointer replacement. Malformed trust updates are rejected automatically, leaving the previous active Root CA intact.
